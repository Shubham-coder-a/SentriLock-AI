# SentriLock AI 🔐

SentriLock AI is a smart security system that integrates RFID authentication, WiFi monitoring, and camera surveillance to detect unauthorized access and protect networks.

## Features

* RFID Based Access Control
* WiFi Device Monitoring
* Unauthorized Device Detection
* Camera Surveillance
* Security Alert System
