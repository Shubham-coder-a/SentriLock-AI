# 🔐 SentriLock AI

AI Powered Smart Security and Network Monitoring System using **RFID, Camera Surveillance, and WiFi Monitoring**.

---

## 📌 Overview

SentriLock AI is an intelligent security system designed to detect unauthorized access, monitor connected devices, and send instant alerts.  
It combines **RFID authentication**, **network scanning**, and **camera surveillance** into one smart solution.

---

## 🚀 Features

- 🔑 RFID Based Access Control
- 📶 WiFi Device Monitoring
- 🚨 Unauthorized Device Detection
- 📷 Camera Surveillance
- 📩 Telegram Instant Alerts
- 🧠 Face Detection with OpenCV
- 📊 Live Dashboard (Flask UI)
- 📝 Security Logs Tracking

---

## 🛠️ Technologies Used

- Python
- Flask
- OpenCV
- RFID Hardware
- Network Scanning (ARP)
- Telegram Bot API
- HTML / CSS Dashboard
- IoT Security

---

## 📂 Project Modules

- `wifi_scanner.py` → Detect devices on network
- `camera_capture.py` → Capture intruder photo
- `face_detection.py` → Detect faces in image
- `telegram_alert.py` → Send alerts/photos
- `dashboard.py` → Web dashboard
- `logger.py` → Save logs
- `rfid_reader.py` → RFID access system
